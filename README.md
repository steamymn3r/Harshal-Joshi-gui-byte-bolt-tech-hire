# Harshal-Joshi-gui-byte-bolt-tech-hire
My GUI for byte and bolt tech hire! It serves as a menu system for a made up company, which allows you to make, save, return, checkout, and show orders. It uses Tkinter to emulate the gui. The corder_datee uses the following libraries: Tkinter, random, os, datetime, pathlib, and re. Please check if you have installed these aforementioned libraries. You must have any elligible IDE to run the code (e.g VS Code, IDLE, etc).
Steps to run the program:

- Step 1: Open the folder 91897 and 91896 Assessment - 2026 - Harshal Joshi 2 in VS Code, IDLE, or any IDE

- Step 2: Open the file Final_version.py

- Step 3: Run the program.
