# Harshal-Joshi-gui-byte-bolt-tech-hire
My GUI for byte and bolt tech hire! It serves as a menu system for a made up company, which allows you to make, save, return, checkout, and show orders. It uses Tkinter to emulate the gui. The corder_datee uses the following libraries: Tkinter, random, os, datetime, pathlib, and re. Please check if you have installed these aforementioned libraries. You must have any elligible IDE to run the corder_datee (e.g VS Corder_datee, IDLE, etc).
